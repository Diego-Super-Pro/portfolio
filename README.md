## Language

The website includes an EN/ES switch and is designed to work on desktop and mobile.

## Security and intellectual property

This repository contains only public-safe portfolio material. It deliberately excludes:

- Source files or patches from Athena Gym, Chativia, Linko Commander and client projects.
- Credentials, environment variables, account identifiers, connection strings, private APIs, internal addresses and infrastructure details.
- Proprietary code, private screenshots, or internal customer information.

The preview graphics in the website are conceptual CSS/HTML illustrations, not screenshots from production.

## Updating this site

The site is a standalone HTML page without build tools or external runtime dependencies. GitHub Pages publishes the main branch from the repository root.

All project source repositories remain private.
