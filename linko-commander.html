01 / Descripción

Qué hace este proyecto

Servidor propio que expone operaciones controladas mediante Model Context Protocol (MCP). Permite que un asistente autorizado interactúe con archivos, terminal, Git, navegador, procesos y emuladores Android. No es un plugin de WordPress ni es lo mismo que Linko IDE.

Participación en el proyecto

Diseño de servidor MCP, catálogo de Tools, integración con asistentes, herramientas locales y validación de seguridad por permisos.

Estado: Herramienta privada operativa con alcance controlado; sin demo pública de las operaciones internas.

02 / Funcionalidades

Áreas desarrolladas

Tools para agentes

Operaciones tipadas que un asistente puede invocar para trabajar en proyectos locales.

Desarrollo y control de código

Lectura y edición de archivos, búsquedas, comandos, procesos e integración con Git.

QA y navegación

Operaciones de navegador, escritorio Windows y dispositivos Android mediante ADB.

Límites de acceso

Directorios permitidos, separación de operaciones de lectura/escritura y controles para acciones sensibles.

Project summary (English)

Private MCP (Model Context Protocol) server for AI-assisted engineering workflows. Exposes controlled tools for local files, terminal, Git, browser, processes and Android QA. Node.js and TypeScript. Source code and infrastructure are private.
